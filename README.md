# Manufacturing Defect Traceability & CAPA

## 📌 Project Overview

The **Manufacturing Defect Traceability & CAPA** project is a Python-based application designed to help manufacturing industries record, track, and analyze product defects. It helps identify quality issues, trace defective products, and manage Corrective and Preventive Actions (CAPA) to reduce repeated defects and improve product quality.

The application provides a simple interface to organize defect information and support better quality-control decisions.

## 🎯 Objectives

- Track and record manufacturing defects.
- Maintain defect details for traceability.
- Identify recurring quality issues.
- Manage corrective and preventive actions (CAPA).
- Support data-driven quality improvement.
- Improve manufacturing quality and reduce repeated errors.

## ✨ Key Features

- **Defect Tracking:** Record and manage manufacturing defect information.
- **Traceability:** Maintain defect-related records for easier investigation.
- **CAPA Management:** Document corrective and preventive actions.
- **Data Visualization:** Present quality-related information through a dashboard.
- **User-Friendly Interface:** Interact with the application through a simple web interface.
- **Quality Analysis:** Help identify patterns and areas for improvement.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd manufacturing-defect-traceability-capa
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your browser. If it does not open automatically, visit:

`http://localhost:8501`
